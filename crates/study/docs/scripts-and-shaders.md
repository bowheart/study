# Scripts, shaders and imports

## Script nodes

A `script` node fills itself with nodes generated by a JavaScript file (`scriptUri`, relative to
the .pen file). Give the node a fixed `width` and `height`; the generated nodes are positioned
inside it with `x`/`y`.

```js
/**
 * @schema 2.11
 * @input count: number = 12
 * @input color: color = #3B82F6
 * @input style: enum("dots", "bars") = "dots"
 */
const nodes = [];
for (let i = 0; i < pencil.input.count; i++) {
  const size = 8 + Math.random() * 16;
  nodes.push({type: "ellipse", x: Math.random() * (pencil.width - size), y: Math.random() * (pencil.height - size),
              width: size, height: size, fill: pencil.input.color});
}
return nodes;
```

- The `@schema 2.11` tag is required. Inputs: `number`, `string`, `boolean`, `color`, `ref`, `enum(...)`.
- The script sees `pencil.width`, `pencil.height` and `pencil.input.<name>` (node `inputs` override
  the declared defaults) and returns an array of nodes in the .pen schema.
- `Math.random()` is seeded, so output is stable between renders.
- Generated nodes aren't saved in the file and can't be addressed by id; edit the script or its inputs.

## Shader fills

`{type: "shader", url: "effect.frag", uniforms: {...}}` runs a WebGL 1 fragment shader over the
node. Annotate uniforms in a doc comment above them:

- `@resolution` (vec2): the node's size; `gl_FragCoord.xy / u_resolution` is 0..1 with y up.
- `@time` (float): seconds since the canvas started — animates the fill.
- `@mouse` (vec2): the pointer position in `gl_FragCoord` space.
- `@default <value>`: the value when `uniforms` doesn't set one. `@color`, `@label`, `@min`/`@max`/`@range` are UI hints.
- `sampler2D` uniforms take an image URL (from `uniforms` or `@default`). `@sdf` instead binds a signed
  distance field of the node's shape (`r` = distance, positive inside; `gb` = gradient direction), and
  `@backdrop` binds what is drawn behind the node (for glass and refraction effects).
- `texture2D(tex, uv)` samples with `uv` in 0..1, y up; `textureSize(tex, 0)` gives the texture size.

## Imports

A document's top-level `imports` maps aliases to other .pen files (`{"ui": "kit.lib.pen"}`).
Instance an imported component with `{type: "ref", ref: "ui:componentId"}` and use its variables
as `"$ui:name"`. Imported files are read-only from here; edit them in their own file.
